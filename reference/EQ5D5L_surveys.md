# EQ-5D-5L multiple survey example data

A dataset containing dimension values and vas score for 1000 respondents
across 10 surveys. Data was synthetically generated.

## Usage

``` r
EQ5D5L_surveys
```

## Format

A [tibble](https://tibble.tidyverse.org/reference/tbl_df-class.html)
with 10000 rows and 11 variables:

- surveyID:

  Survey ID

- respondentID:

  Respondent ID

- sex:

  Respondent sex

- age:

  Respondent age

- mobility:

  Mobility dimension

- self_care:

  Self-care dimension

- usual:

  Usual activities dimension

- pain:

  Pain/discomfort dimension

- anxiety:

  Anxiety/depression dimension

- vas:

  VAS score

- time_index:

  Relative time within survey framework

- dummy:

  Random roolean variable
